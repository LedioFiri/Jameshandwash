# James Hand Carwash website

A dependency-free static website for James Hand Carwash in Leatherhead. Open `index.html` directly or serve this folder with any static web server.

## Before launch

1. Replace the commented canonical/Open Graph/Twitter URL placeholders in `index.html` and `privacy.html` with the final HTTPS domain, then uncomment them.
2. Confirm the current Google rating and review count, because those can change over time.
3. Confirm the full opening-hours schedule before adding it. The current site deliberately links to Google instead of inventing hours.
4. Confirm the legal name of the privacy data controller and the eventual hosting provider/log-retention details, then update `privacy.html`.
5. Replace `assets/hand-car-wash.webp` with verified James Hand Carwash photography when available. Keep the same filename, dimensions and crop, or update the image attributes. The current image is free illustrative photography by Avenir Visuals under the Unsplash licence and is visibly credited on the page.
6. Recheck all phone, directions and review links on the deployed site.

## Third-party content

The website loads no third-party content on first view. Google Maps is loaded only after a visitor explicitly selects “Load Google Map”. The photograph is self-hosted.
